ต้องผ่านด่าน 1-5

ด่านที่ 1: ดินแดนแห่งจุดเริ่มต้น

ภารกิจที่ 1/3 : เลือกสัญลักษณ์ที่ถูกต้อง

สัญลักษณ์ใดใช้แสดง "จุดเริ่มต้น" (Start) หรือ "จุดสิ้นสุด" (End) ของผังงาน?

📚 สารานุกรมสัญลักษณ์ผังงาน (Flowchart)

คู่มือเรียนรู้สัญลักษณ์เวทมนตร์ พร้อมเสียงอ่านอธิบายภาษาไทย

Start / End

จุดเริ่มต้น / จุดสิ้นสุด (Terminal)

รูปวงรี (Oval)

ใช้เริ่มต้นและสิ้นสุดการทำงานของโปรแกรมหรืออัลกอริทึมเสมอ

Process

การประมวลผล (Process)

รูปสี่เหลี่ยมผืนผ้า (Rectangle)

ใช้คำนวณ กำหนดค่า หรือทำกิจกรรมปฏิบัติต่างๆ เช่น การแปรงฟัน การต้มน้ำ

Decision

การตัดสินใจ (Decision)

รูปสี่เหลี่ยมข้าวหลามตัด (Diamond)

ใช้เปรียบเทียบเงื่อนไข โดยจะมีทางออกอย่างน้อย 2 ทาง คือ ใช่ (True) หรือ ไม่ใช่ (False)

Input / Output

รับข้อมูล / แสดงผล (Input/Output)

รูปสี่เหลี่ยมด้านขนาน (Parallelogram)

ใช้รับค่าข้อมูลเข้าสู่โปรแกรม หรือแสดงผลข้อมูลทั่วไปโดยไม่ระบุอุปกรณ์

O

จุดเชื่อมต่อ (Connector)

รูปวงกลม (Circle)

ใช้รวมเส้นทาง หรือเชื่อมต่อจุดการทำงานผังงานในหน้าเดียวกัน

➔

ทิศทางการทำงาน (Flowline)

เส้นลูกศร (Arrow)

ใช้ระบุลำดับทิศทางการไหลของการทำงานจากขั้นตอนหนึ่งไปอีกขั้นตอนหนึ่ง

🎉

เก่งมากเลย!

คุณตอบถูกต้องแล้ว รับพลังเวทมนตร์เพิ่ม 10 คะแนน
